# 受験者のみなさんへ（HSS動画試験）

※ やさしい日本語。多言語版は本物の問題が決まってから作る（`docs/annai-en.md` など、学科版と同じ構成）。

## 試験のやり方

1. アプリを開いて「HSS動画 本試験を受験する」を押す
2. パスワードと名前を入れる（名簿と同じ書き方）
3. 「テストを開始する」を押すと、**動画の準備**が始まる。電波の良い場所で待つ。準備が終わると1問目が出る。この間、時間は減らない
4. 1問ごとに短い動画がある。**▶ を押して、最後まで見る**。見終わると答えが4つ出る
5. 動画は **1問につき2回まで** 見られる。途中で止めた動画の続きを見るのは、回数に入らない
6. 答えを選んで「次へ」。前の問題に戻って直せる
7. 全部答えたら「試験を終了する」を押す。押すまで送信されない

## 注意

- 制限時間は **30分**。動画の準備の時間は入らない
- 試験中にほかのアプリを開くと、回数と時間が記録される
- 動画は早送りできない
- 音が出ることがある。イヤホンがあれば使う（会場の指示にしたがう）
- 電波が悪くて動画の準備に失敗したら、電波の良い場所で「テストを開始する」をもう一度押す

## 練習

「デモ問題を受験する」で3問だけ練習できる。デモの動画は何回でも見られる。終わると正解と解説が出る。結果は送られない。
